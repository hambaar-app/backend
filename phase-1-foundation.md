# Phase 1: Foundation

This phase establishes the core foundation for the application, including:

- Core module structure and organization
- Authentication and authorization setup
- Database schema and Prisma configuration
- Core enums and constants
- Shared utilities and interceptors
- Basic module scaffolding

## Modules Covered

- Auth (OTP, sender, authorization)
- User management
- Vehicle management
- Package handling
- Pricing and financial operations
- Notifications and messaging
- S3 storage integration
- Dashboard and mapping features

## Key Decisions

- NestJS module organization with feature-based grouping
- Prisma ORM for database interactions
- JWT-based authentication
- S3 for file storage
- Class-validator for DTO validation
